# Sql_Exploratory_Data_Analysis
Exploratory Data Analysis (EDA) of a SQL Data Warehouse built from Gold-layer datasets to uncover actionable business insights.


Welcome to the **Sql Exploratory Data Analytics Project** repository!

This repository showcases an end-to-end data lifecycle project. It demonstrates a professional approach to data engineering and analytics, featuring automated cleaning scripts, clear documentations designed to drive informed business decisions.

<br>


*Note: The analysis techniques that are demonstrated in this project can be utilized on any data warehouses with some minor modifications.*


## Project Requirements

### Objective

- **Centralize data:** Build a modern data warehouse using **SQL Server** to consolidate sales data and streamline analytical reporting.


- **Advanced Reporting:** Develop comprehensive reports on customer demographics and product performances using advanced SQL techniques.


### Technical Specifications

- **Data Sources:**  Integrates data from three core systems: dim_customers, dim_products, and fact_sales.

- **Quality Assessment:** Performs a pre-load analysis of CSV files to identify potential **data integrity** issues or inconsistencies.

- **Data Architecture:** Implements a Direct-to-Gold load pattern. Since the source data is pre-processed, this approach minimizes latency and storage costs while maintaining high data quality.

- **Data Analytics:** Taking advantage of the different advanced SQL queries to evaluate key performance indicators (KPIs) and business health.

<br>

---

### EDA and Reporting

Leverage the **Gold Layer** to execute advanced SQL analytics, providing a granular view of business operations:

- **Customer behaviour:** Analyzes purchasing patterns, retention rates, and high-value customer segments.
- **Product Performance:** Evaluates revenue contribution, top-performing product categories/product lines etc.
- **Sales trends:** Measures the year-over-year (YoY) growth and regional performance metrics.

These insights empower stakeholders with key business metrics, enabling strategic decision-making.

<br>
